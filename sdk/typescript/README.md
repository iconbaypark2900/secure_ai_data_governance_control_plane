# @control-plane/sdk

The enforcement-point client, for TypeScript. A port of the Python SDK, not a
reinterpretation: the request body, the outcome vocabulary, and the set of
obligations the control plane is taken to have already applied are identical,
and a generated fixture asserts it.

```bash
npm install @control-plane/sdk
```

## Deciding

```ts
import { ControlPlaneClient } from "@control-plane/sdk";

const cp = new ControlPlaneClient("http://localhost:8000", { apiKey: process.env.CP_API_KEY });

const decision = await cp.decide({
  principalId: "agent://support-bot",
  principalType: "agent",
  action: "infer",
  resourceUrn: "pg://public.customers",
  payload: "Refund jane.doe@acme.com, SSN 536-90-4432.",
});

decision.effect;             // "allow"
decision.payload;            // "Refund <pii.email:68ccacd2…>, SSN [REDACTED:pii.ssn]."
decision.obligationTypes();  // ["log", "redact", "route"]
```

## Enforcing

`enforcing` takes the work as a callback, and reports the outcome when that work
finishes — enforced if it returned, refused if it threw.

```ts
const sent = await cp.enforcing(
  decision,
  async (payload) => sendUpstream(payload),
  { canSatisfy: ["route"] },
);
```

Reporting at the moment the obligations merely check out is premature: the
action has not happened yet, and if a later step fails the record ends up saying
"enforced" behind something that never took place. In Python this is a context
manager; here it is a callback, which is not only a translation detail — there
is no way to obtain the payload without also handing over the work that uses it,
so the reporting cannot be skipped by accident.

Use `cp.enforce(decision, canSatisfy)` only when acting on the decision is the
*last* thing that happens.

## Three properties that are requirements, not conveniences

**It fails closed.** If the control plane cannot be reached, `decide` returns a
denial rather than throwing something a caller might shrug off. An enforcement
point that lets traffic through when its authority is unavailable provides no
control at all — it provides the appearance of one, which is worse. A 401 or 403
is a denial too: our own credentials being wrong is not a reason to proceed
unchecked. Pass `failClosed: false` only knowingly.

**Obligations are binding.** `decision.enforce()` throws `ObligationUnsatisfied`
for any duty this enforcement point has not declared it can carry out. "Allow,
but redact the SSNs" must never degrade into "allow". The control plane applies
`redact`, `annotate`, `log` and `ttl` itself; anything else is yours to declare
in `canSatisfy`.

**Only the pure authorisation question is cached.** A decision carrying a payload
is never cached, because the payload is part of what was decided. Neither is an
`explain`, nor an approval redemption, which must happen exactly once.

## Outcomes

```ts
await cp.reportOutcome(decision, Outcome.ENFORCED, { discharged: ["redact"] });
await cp.reportPartial(decision, ["watermark"], "no watermarker configured");
```

`reportOutcome` never throws. By the time it runs the action has already been
taken, and failing the caller over a bookkeeping round trip would turn a
reporting problem into an outage. An outcome that does not arrive shows up
server-side as *unreported*, which is the detection path — silence means
"nothing is known", not "it went fine".

`partial` earns its place: a point that discharged three duties and skipped the
fourth would otherwise have to report something false either way.

## Approvals

```ts
if (decision.needsApproval) {
  const approval = await cp.awaitApproval(decision.approvalId!, { timeoutMs: 300_000 });
  if (approval.status === "granted") {
    const redeemed = await cp.decide({ ...request, approvalId: decision.approvalId! });
  }
}
```

Returns on any terminal state — granted, denied or expired — so the caller
decides what to do about a refusal.

## Notes

Requires Node 20+ for global `fetch`; pass your own as `options.fetch` for other
runtimes or for tests.

Cache keys are process-local and are *not* byte-identical to the Python client's:
the two languages format floats and escape non-ASCII differently. What must match
is the request body, and `test/contract.test.ts` asserts that against a fixture
generated by `tools/generate_sdk_contract.py` from the Python SDK itself.

```bash
npm test          # 41 tests, no network
npm run typecheck
npm run build
```
